恢复开发
1. 解压到 E:\ai\_lesson，得到 qijian-writer 文件夹，也可以解压到其它目录。
2. 使用 Node.js 22（归档时为 v22.22.0）和 npm，在项目目录执行：
   npm ci
   npm run check
   npm start
   npm ci 需要联网下载 package-lock.json 锁定的依赖和 Electron。
3. 依赖安装完成后，也可以双击“启动栖简.cmd”。
4. 构建免安装版：
   npm run build:windows -- --config.electronDist=node_modules/electron/dist
5. 构建安装版（先完成上一步）：
   npm run build:installer -- --prepackaged dist/win-unpacked

验证
先创建输出目录：New-Item -ItemType Directory -Force dist/diagnostics
运行 npm run test:smoke；这些脚本使用临时文稿库。
部分视觉测试会生成 dist 截图。installer-e2e-smoke.cjs 需另建隔离的安装测试配置和上下文，旧 dist 中的机器专用配置未保留。
tests 中的 clear-history-and-cleanup.cjs 等维护脚本会改动传入的文稿库，不能对真实文稿库随意运行。

继续开发时需保留的行为
文稿与其历史版本共用本篇文稿的图片目录；不同文稿各自保存图片。
历史版本保留 15 天，同一启动会话记录最新状态。图片清理须遵守引用检查与既有触发时机。
手动备份只含当前文稿和对应图片，不含历史版本，采用压缩备份覆盖旧备份；恢复时互换当前状态和备份。
此次归档只清理开发目录，未改动 E:\ai\_lesson\栖简文稿库 或已安装应用。
README.md 中关于每日自动备份、早期历史逻辑的描述属于旧版，请以当前代码和测试为准。
