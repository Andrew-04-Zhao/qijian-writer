# 栖简

栖简是一款本地优先的个人写作与思维整理桌面应用。首版不包含 AI、账户、订阅或云同步。

## 首版能力

- 文档树、文件夹、回收站和全文搜索
- 所见即所得编辑与常用 Markdown 快捷输入
- 字体、字号、行距、段距、页面宽度和明暗主题
- 自动保存与本地版本历史
- 按标题生成大纲，并切换为基础思维导图
- 图片附件、本地 Markdown 导入与 Markdown/Word/PDF 导出
- 每日自动备份与手动备份
- 数据存放在“文档\\栖简文稿库”，源码和个人文稿相互独立

## 运行

```powershell
npm install
npm start
```

依赖安装完成后，也可以直接双击 `启动栖简.cmd`。

## 数据安全

每次保存都会更新本地文档库；正文发生变化时会按时间间隔生成版本快照。卸载程序不应删除个人数据目录。正式发布前还会增加可视化的数据目录选择和备份恢复流程。
